# Установка Agent Routing Kit по ссылке

Эта инструкция для Claude Code или Codex, когда пользователь просит установить комплект в открытый локальный проект.

1. Определите корень проекта. В Git используйте `git rev-parse --show-toplevel`. Если папка проекта недоступна или выбрать её однозначно нельзя, попросите пользователя указать нужную папку.
2. Скачайте [agent-routing-kit.zip](./agent-routing-kit.zip?raw=true) во временную папку и распакуйте его. Замените `ZIP_URL` на абсолютный адрес ссылки «agent-routing-kit.zip» на этой странице. Если инструкцию открыли как сырой Markdown, возьмите ZIP из корня того же репозитория и той же ветки.

   ```sh
   kit_dir="$(mktemp -d)"
   curl -fsSL 'ZIP_URL' -o "$kit_dir/agent-routing-kit.zip"
   python3 -m zipfile -e "$kit_dir/agent-routing-kit.zip" "$kit_dir"
   ```

3. Прочитайте `agent-routing-kit/INSTALL.md` из распакованного комплекта. Запустите `install.py` с `--tool codex` или `--tool claude-code` и фактическим путём `--project`. Первый запуск сделайте без `--apply`. Если план относится к нужному проекту и конфликтов нет, повторите команду с `--apply`.
4. Повторите проверку плана. Перечислите установленные файлы и предложите открыть новую сессию в том же проекте. Пробный запрос есть в README выбранного инструмента внутри архива.

Для установщика нужен Python 3.8 или новее. Для сетевого доступа и защищённой записи используйте штатные запросы разрешений. Если чат не может скачать ZIP, дайте пользователю ссылку на архив и попросите приложить файл. Если запись ограничена, в инструкции внутри ZIP есть способ запуска из обычного терминала.

# Установка Agent Routing Kit из GitHub

Эта инструкция для Claude Code или Codex, когда пользователь просит установить комплект по ссылке в открытый локальный проект.

1. Определите корень проекта. Для репозитория Git используйте `git rev-parse --show-toplevel`. Если папка проекта недоступна или выбрать её однозначно нельзя, попросите пользователя указать нужную папку.
2. Скачайте [agent-routing-kit.zip](https://raw.githubusercontent.com/artemknizhnikov16-code/agent-routing-kit/main/agent-routing-kit.zip) и распакуйте его во временную папку. Пример для macOS и Linux:

   ```sh
   kit_dir="$(mktemp -d)"
   curl -fsSL 'https://raw.githubusercontent.com/artemknizhnikov16-code/agent-routing-kit/main/agent-routing-kit.zip' -o "$kit_dir/agent-routing-kit.zip"
   python3 -m zipfile -e "$kit_dir/agent-routing-kit.zip" "$kit_dir"
   ```

3. Откройте `agent-routing-kit/INSTALL.md` внутри распакованного комплекта и выполните его шаги. Выберите `--tool codex` или `--tool claude-code` по открытому приложению. Сначала запустите `install.py` без `--apply`, чтобы проверить план. Если план относится к нужному проекту и конфликтов нет, повторите команду с `--apply`.
4. Повторите проверку плана. Сообщите, какие файлы установились, и предложите открыть новую сессию в том же проекте. Пробный запрос есть в README выбранного инструмента внутри архива.

Комплект требует Python 3.8 или новее. Для защищённой записи и сетевого доступа используются штатные запросы разрешений. Если чат не может скачать ZIP, дайте пользователю прямую ссылку выше и попросите приложить файл. Если скачать удалось, а запись ограничена, в инструкции внутри ZIP есть способ запуска из обычного терминала.
